# Collection de sables — carte interactive

Carte mondiale interactive des prélèvements.

- Ouvrir `index.html` sur GitHub Pages.
- Charger un CSV depuis le bouton « Charger un CSV ».
- Le CSV accepte les en-têtes français de l'inventaire Excel, notamment Latitude et Longitude.
- Les points sont regroupés automatiquement quand on dézoome.

Le fichier `data.csv` est un modèle vide. Pour garder les données privées, ne mets pas de données personnelles ou sensibles dans ce dépôt public.
